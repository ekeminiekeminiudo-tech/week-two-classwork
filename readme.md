definition of  variable?
variable is a name giving to memory or storage location that stored data

data type is the kind of data a variable can store and how the data can be used.

Examples of data type
int: Store whole number(e.g 20, 100)
float: number with decimal (40.3)
string: store text and character(hello, ekemini)
boolean: use true or false value(true, false)

operator is a symbol or keyword use to perform operation on value  or variable in programming

types of operator
arithmetic operator: +,*,/,-
comparison operator: ==,<,>,!=
logical operator: not,or,and
